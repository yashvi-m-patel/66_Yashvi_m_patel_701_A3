# Question 8: Student CRUD with Sequelize

Uses a local SQLite database file; no database server is needed.

```powershell
cd ques8
npm install
npm start
```

In a second terminal:

```powershell
cd ques8/client
npm install
npm run dev
```

Open http://localhost:5178. Express runs on port 3008. Student records are saved in `students.sqlite`.
